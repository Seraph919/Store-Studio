# Contributing to Store Studio

Thank you for helping improve this self-hosted e-commerce project.

- Open an issue before major architecture or behavior changes.
- Keep pull requests focused and explain the user-visible change.
- Add tests for behavior changes where possible, and run the frontend build and backend tests.
- Document changes to environment variables, API behavior, or database migrations.
- Do not submit live store credentials, customer records, privately owned imagery, or merchant-specific branding.
- Preserve the one-store-per-installation model unless an architectural change is explicitly proposed.

By contributing, you confirm you have the rights to submit the contribution under the project's license.
