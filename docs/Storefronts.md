# Storefronts and templates

Store Studio is a **single-store, self-hosted** application. Each installation has one public storefront at `/`, with a private owner dashboard at `/seller`. There is no global marketplace and no public seller registration.

## Templates

The visual editor offers **Minimal**, **Modern**, and **Editorial** storefront layouts. Each template retains its own homepage sections and imagery when you switch templates; colors and branding can be adjusted in Design Studio.

## Configuration

The store owner can change the logo, hero media, section ordering, featured products, product image framing, footer, and optional ring-size guide. Product and category records come from the database, not a hard-coded merchant catalog.
